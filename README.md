# Eye-Gaze-Based-Adaptive-Learning

EYE_GAZE EMERGENCY CONFIRMATION,ALERT,WEB NOTIFICATION HANDLING

The Eye_Gaze system needs the AI Engine to 
be integrated with a server to let the following tasks to be achieved :  
1)Needs to confirm the current status of patient if it is abnormal then needs to send 
alert through SMS to the respective caretakers for further actions  
2)Notifies the Hospital authority the condition of the patient through real time 
dashboard showing the details of patients under state of emergency 
3)To store the logs of patients in the DataBases for further statistical analysis and 
monitoring by the authorities
